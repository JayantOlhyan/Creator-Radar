# CreatorRadar — Product Requirements Document (PRD)

## 1. Product Summary

CreatorRadar is an open-source creator-intelligence platform designed to monitor creators across multiple platforms, detect new content, analyze content patterns, and convert those patterns into original content opportunities tailored to the user's expertise.

## 2. Core Value Proposition

Translating observed content success mechanisms into high-value, original user opportunities while strictly enforcing **Inspiration ≠ Replication**.

## 3. Explicit Non-Goals

The following features are strictly prohibited and outside product scope:
* Automatic reposting systems
* Script scraping or direct copy-paste generation
* Automated engagement bots / auto-likers
* Social media auto-scheduling / auto-posting
* Instagram-only single platform lock-in
* Generic unguided AI text generation
* Follower growth bots

## 4. User Persona & Use Cases

* **Technical Founders & Engineers**: Monitoring domain thought leaders to extract breakdown structures and apply them to their own software projects.
* **Domain Experts & Creators**: Monitoring cross-platform trends and structuring original insights into compelling narratives.

## 5. Product Features & Milestones

* **Phase 0 (Current)**: Architecture foundation, platform abstraction, AI provider drivers, async queue, database schema, event model, testing.
* **Phase 1**: Source acquisition mechanism investigation & first supported platform integration.
* **Phase 2**: Transcription & structural content analysis pipeline.
* **Phase 3**: Pattern discovery engine & knowledge-grounded personalization.
* **Phase 4**: Telegram notifications & interactive opportunity builder.
